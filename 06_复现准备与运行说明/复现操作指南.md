# 复现操作指南

## 1. 环境准备（必需）

目标环境为Windows 64位、Python 3.14；原验证环境为Windows 11、Python 3.14.6 AMD64。离线wheel针对这一平台，不适用于Mac、Linux、32位Python或Python 3.13等其他版本。没有Python时请先安装相应解释器并配置PATH，包含pip和venv组件；本包没有附Python安装程序。

完整复制整个“**T14 自动化数据清洗流水线**”文件夹后使用，保持01、05、06的相对位置；路径中有空格和中文可以保留。不需要把原D盘工程路径或原私有目录搬到新电脑。不要只取02中的测试源码单独运行。

进入本目录，双击 `00_check_materials.cmd`：仅核验原工程354项文件、冻结清单、原始数据哈希及19个离线wheel哈希，不读取income内容、不训练、不评分。检查成功不等于F1达标。

然后双击 `01_install_dependencies.cmd`：在课题文件夹下创建独立的“复现运行环境/.venv”，仅从本地离线依赖包安装锁定版本，执行pip依赖一致性检查。安装依赖不运行清洗或实验。无需使用原电脑现存的虚拟环境。

快捷入口优先使用 `py -3.14`；没有Python Launcher时使用PATH中的 `python`。若提示找不到Python 3.14，先修复Python安装和PATH，再重试。不要通过放宽锁定版本来绕过不匹配环境。

| 文件 | 用途 | 是否训练下游分类器 |
|---|---|---|
| `00_check_materials.cmd` | 只核验材料及哈希 | 否 |

运行结束后检查退出码和实际输出，不要把历史报告误当成此次运行结果。`.cmd`暂停前显示EXIT_CODE，0代表命令成功；F1复现命令成功不意味着达标，也不意味着与历史数值完全一致，应查看下述差异核对结果。

若不使用快捷入口，可在本目录PowerShell中执行：

# 以下三项按需运行，不会自动串行执行：

## 3. 输出位置和核对方式

清洗入口生成 `cleaned.csv`、`detected_cells.csv`、`review.csv`、`repair_report.md/json`、`audit.jsonl`、`rolled_back.csv` 等，具体以该次实际输出为准。使用自有Adult数据时，可参照01的README，直接调用 `run_pipeline.py --input ... --output ...`；输出必须使用新路径。

清洗结果还可仅凭审计文件重新恢复，以下命令中的“某次清洗目录”替换为真实运行路径：

```powershell
../复现运行环境/.venv/Scripts/python.exe -B ../01_流水线源码/tools/rollback_data.py --cleaned "某次清洗目录/cleaned.csv" --audit "某次清洗目录/audit.jsonl" --output "某次清洗目录/再次回滚.csv" --expected-report "某次清洗目录/repair_report.json"
```

测试副本中的 `reports/test_results.json` 及 `logs/reproduction_full_unit_tests.log` 反映新执行结果；测试执行期间逐项输出写入该完整日志，可另行打开查看。02目录仍保存原交付证据。

完整F1入口读取05原始文件并校验哈希，使用已冻结的行索引、五个种子20260601—20260605、3%/10%/20%噪声、原分类器和相同验证预算；不新增搜索。七版本为干净、脏数据、V2、V3、V3.1、V3.2和J。输入不需要私有历史模型或预测文件，脚本重新训练。它输出 `reproduced_runs.csv`、`training_choices.csv` 和 `reproduction_result.json` 等，最后记录与正式105条版本结果的最大指标差异及 `matches_within_1e_12`。请保留差异，不要为了消除差异调整数据、参数或评价公式。

也可在01目录按下列命令直接复现，输出目录必须尚不存在：

```powershell
../复现运行环境/.venv/Scripts/python.exe -B tools/reproduce_f1.py --adult-train "../05_原始数据（含标签，请勿公开）/adult.data" --adult-test "../05_原始数据（含标签，请勿公开）/adult.test" --output "../复现F1私有输出_自定义新名称"
```

历史正式评分入口 `score_once.py` 的一次性保护保留，勿通过删除评分标记重复验收。`audit_independence.py`、`train_models.py` 等原验收编排工具留作源码证据，可能依赖原历史工作区；换电脑请用这里提供的 `reproduce_f1.py` 入口，而非重新执行历史整套验收编排。
